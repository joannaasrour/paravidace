# Paravidace website

Next.js site for Paravidace (contracting, engineering, architecture, consultation).

- Edit projects, photos and contact details in `app/data.js`.
- Put photos in `public/img/` and refer to them as `/img/your-photo.jpg`.
- Deploy: import this repository on Vercel; it detects Next.js automatically.

Local preview: `npm install` then `npm run dev`.
